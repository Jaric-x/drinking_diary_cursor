# 产品需求文档（PRD）
# 微醺笔记 (Drinking Diary) Phase 3 - 图片浏览与社交分享

## 1. 产品概述

### 1.1 背景与目标
为了提升用户对美好饮酒时刻的回顾体验，并促进应用的自然传播，三期功能将重点优化 **图片浏览体验** 并新增 **社交分享能力**。
通过模仿 iOS 原生相册的沉浸式查看模式，提升视觉享受；通过精美的分享海报，利用微信社交生态进行裂变传播。

### 1.2 三期核心功能范围
1.  **沉浸式图片浏览**: 改造照片墙交互，新增“照片详情页”，支持高清大图浏览与手势缩放。
2.  **社交分享海报**: 在详情页提供分享入口，生成包含笔记核心信息（照片、酒名、评分）与小程序码的精美海报，支持分享给好友或保存到相册。

## 3. 页面详细设计

### 3.1 个人酒库页 (My Gallery) - 交互变更

#### 3.1.1 交互逻辑调整
- **旧逻辑**: 点击照片墙中的图片 -> 直接跳转至“编辑笔记页”。
- **新逻辑**: 点击照片墙中的图片 -> 跳转至 **[3.2 照片详情页]**，并传递当前笔记数据。

---

### 3.2 照片详情页 (Photo Detail) - 新增页面

#### 3.2.1 页面容器与设计
- **设计目标**: 让用户完全沉浸在当时那一杯酒的视觉氛围中，减少文字和 UI 元素的干扰。
- **色彩与氛围**: 
  - **背景**: 极致纯黑 (#000000)。
  - **光影**: 顶部和底部区域有极淡的黑色渐变遮罩，确保白色图标在任何照片背景下都清晰可见，且不破坏沉浸感。
- **交互手势**: 
  - 支持 **双指捏合 (Pinch)** 缩放查看图片细节。
  - 支持 **双击** 放大/还原图片。
  - 支持 **左右滑动** 切换上一张/下一张笔记照片。

#### 3.2.2 页面元素
1.  **顶部导航栏 (极简模式)**:
    - **左侧**: 仅保留一个极简的白色返回箭头 (IconChevronLeft)，无任何文字标题。
    - **右侧**: 空置。
2.  **核心图片区**:
    - **内容**: 笔记的高清大图。
    - **布局**: 以 **Aspect Fit (等比缩放)** 模式居中展示，确保完整还原拍摄时的画面。
3.  **底部操作栏 (悬浮)**:
    - **位置**: 整体下移至屏幕底部安全区边缘 (距底部约 40px)，远离图片中心区域。
    - **按钮形态**: **16px 大圆角矩形**，符合 iOS 18 新设计语言，触控面积更大，视觉稳重。
    - **元素**: 
      1.  **编辑按钮**: 
          - **材质**: 深灰色半透明毛玻璃 (White 10% + Blur)，点缀细微白色描边。
          - **内容**: "编辑笔记" 文字。
          - **交互**: 点击跳转至该笔记的 [编辑笔记页]。
      2.  **分享按钮**: 
          - **材质**: **纯白色高亮材质**，具有极强的视觉优先级。
          - **内容**: "分享图片" 文字。
          - **交互**: 点击触发 **[3.3 分享海报弹窗]**。

---

### 3.3 分享功能 (Share) - 新增功能

#### 3.3.1 分享海报弹窗
- **触发**: 点击照片详情页的“分享”按钮。
- **设计理念**: 分享海报不再是一个简单的截图，而是一个经过精心排版的虚拟纸质杂志封面。
- **UI 结构**: 
  - **样式**: 居中模态框 (Modal 风格)。
  - **背景**: 叠加 **60% 透明度的黑色** + **高强度高斯模糊 (Backdrop Blur)**，营造沉浸感。
  - **卡片**: 纯白色高质感卡片，拥有 **24px 的大圆角**。
  - **操作按钮组**: 位于海报下方。

#### 3.3.2 海报视觉设计 (Canvas 生成)
海报需通过代码动态绘制，包含以下元素 (从上至下排列)：
1.  **核心影像 (视觉中心)**:
    - **尺寸比例**: **1:1 完美正方形**。
    - **裁剪方式**: **Aspect Fill (居中填充)**。消除原图比例不一带来的混乱感，提升“摄影作品”格调。
2.  **信息层级**:
    - **酒名**: 大字号、加粗的黑色字体，居中排列，展现“今日主推”仪式感。
    - **评分**: 精致的橙色五星图标紧随其后，作为视觉点缀。
3.  **品牌落款区** (底部):
    - **布局**: 底部留出充足的呼吸感空间。
    - **左侧**: 优雅的中文品牌名 "微醺笔记" 及 Slogan "记录每一次微醺时刻"。
    - **右侧**: 小程序二维码 (圆形或方形)。
4.  **整体风格**: 
    - **克制**: 去掉不必要的指示器和装饰。
    - **留白**: 强调呼吸感，让笔记像一张明信片。

#### 3.3.3 分享操作逻辑
在海报预览下方提供两个功能明确的动作：
1.  **微信发送**:
    - **样式**: 标志性的 **微信绿色图标** (社交核心)。
    - **功能**: 调用 `button open-type="share"`，将生成的海报图片发送给微信好友/群。
2.  **关闭**:
    - **样式**: **半透明毛玻璃圆形按钮** (White 10% + Blur) + 关闭图标 (X)。
    - **功能**: 关闭弹窗。

## 4. 技术实现建议

### 4.1 图片预览
- 考虑使用微信小程序原生组件 `swiper` 配合 `movable-area` + `movable-view` 实现手势缩放，或者探索 `wx.previewMedia` 是否能满足自定义按钮 (编辑/分享) 的需求。若原生 API 限制较多，建议使用自定义页面实现。

### 4.2 海报生成 (Canvas)
- 使用 `wx.createCanvasContext` (旧版) 或 `Canvas 2D` (新版推荐) API。
- **跨域图片处理**: 笔记照片若存储在云存储，需先 `wx.getImageInfo` 下载到本地临时路径再绘制。
- **二维码获取**: 需后端/云函数调用 `wxacode.getUnlimited` 接口生成小程序码，并缓存以提升性能。

### 4.3 权限管理
- 保存图片时需检查用户授权状态，优雅处理拒绝授权的情况。
