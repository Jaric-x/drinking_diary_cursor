# 产品需求文档（PRD）
# 微醺手记 (Drinking Diary) Phase 4 - 新用户三阶段使用演示

## 1. 产品概述

### 1.1 背景与目标
新用户首次进入小程序时，容易因为不清楚核心玩法而快速流失。为降低上手门槛、提升首日激活与内容创作转化，四期功能新增 **首页新手演示弹窗**：
- 仅针对识别为“新用户”的账号触发；
- 通过分阶段视频演示 + 简要文案，帮助用户理解产品价值与关键操作；
- 在第三阶段引导用户进入照片墙创作，强化“记录与展示”心智。

### 1.2 四期核心功能范围
1. **新用户识别与触发**：用户首次打开小程序时触发演示弹窗。
2. **三阶段演示流程**：用户需点击“下一步”逐步完成 3 个阶段观看。
3. **跳过能力**：支持用户在任意阶段主动点击“跳过”，直接结束演示流程。
4. **阶段内容呈现**：每阶段包含 1 个演示视频 + 1 段简要说明文字（不展示阶段标题区）。
5. **流程完成与状态落库**：完整观看或主动跳过后，均标记为已完成引导，不再重复自动弹出。

---

## 2. 功能架构

### 2.1 页面流转图（新增）
```
[首页]
  │
  └── 若识别为新用户 ──> [新手演示弹窗]
                          │
                          ├── 点击 [跳过]
                          │        └── 关闭弹窗，回到首页
                          │
                          ├── 阶段1：产品介绍（视频+文案）
                          │        └── 点击 [下一步]
                          ├── 阶段2：如何创建笔记（视频+文案）
                          │        └── 点击 [下一步]
                          └── 阶段3：照片墙展示与创作邀请（视频+文案）
                                   └── 点击 [开启我的微醺手记]
                                            │
                                            └── 关闭弹窗，回到首页并可继续操作
```

### 2.2 触发原则
- **触发时机**：用户进入首页并完成用户信息初始化后判断。
- **触发对象**：首次进入小程序的新用户。
- **触发频率**：默认仅自动弹出 1 次；完整看完或主动跳过后永久不再自动弹出。

## 3. 页面与交互设计

### 3.1 首页新手演示弹窗（新增）

#### 3.1.1 展现形式
- **样式**：全屏半透明遮罩 + 居中模态弹窗（避免误触首页内容）。
- **焦点策略**：弹窗出现后，用户主注意力聚焦在视频区与“下一步”按钮。
- **交互约束**：阶段 1~2 提供“下一步”；阶段 3 提供“开启我的微醺手记”主按钮；所有阶段均提供“跳过”。

#### 3.1.2 公共 UI 元素
1. **视频演示区**
   - 每阶段 1 个短视频，循环播放。
   - 弱网场景下需有加载态与失败重试提示。
2. **文案说明区**
   - 每阶段 1~2 行简明文案，突出关键价值与操作。
3. **底部操作区**
   - 通用次按钮：`跳过`
   - 阶段 1、2：`下一步`
   - 阶段 3：`开启我的微醺手记`

---

### 3.2 三阶段内容定义

#### 3.2.1 阶段一：产品介绍
- **阶段目标**：让用户快速理解“微醺手记是什么、能帮我做什么”。
- **视频内容建议**：
  - 展示记录一杯酒、查看历史回顾、沉浸式浏览的核心画面。
- **文案示例**：
  - `欢迎来到微醺手记，记录每一次微醺时刻，让灵感与风味被好好珍藏。`

#### 3.2.2 阶段二：如何创建笔记
- **阶段目标**：指导用户完成最核心的首个创作动作。
- **视频内容建议**：
  - 演示从首页进入创建、填写酒名/评分/感受、上传照片并保存。
- **文案示例**：
  - `点击“+”按钮，写下你的酒款、口感和当下心情，轻松完成第一条记录。`

#### 3.2.3 阶段三：照片墙展示与创作邀请
- **阶段目标**：传递成果展示价值，促进首日创作转化。
- **视频内容建议**：
  - 展示个人酒柜照片墙的视觉效果、浏览方式与成就感。
- **文案示例**：
  - `你的每一杯都值得被陈列。现在开始，打造属于你的酒柜照片墙。`
- **按钮文案**：
  - 主按钮：`开启我的微醺手记`

## 4. 状态机与业务逻辑

### 4.1 用户状态定义
- `isNewUser = true`：未完成新手演示（默认新账号）。
- `isNewUser = false`：已完成新手演示，不再自动弹出。

### 4.2 演示流程状态
- `currentStep`: 1 | 2 | 3
- `stepViewed`: `{1: boolean, 2: boolean, 3: boolean}`（用于流程容错）
- `onboardingCompleted`: boolean
- `onboardingFinishType`: `completed` | `skipped`

### 4.3 关键流程规则
1. 进入首页后判断 `isNewUser`，若为 `true` 则打开弹窗并初始化 `currentStep = 1`。
2. 用户点击“下一步”时，切换到下一阶段。
3. 用户在任意阶段点击“跳过”后：
   - 设置 `onboardingCompleted = true`；
   - 设置 `onboardingFinishType = skipped`；
   - 持久化 `isNewUser = false`（本地 + 服务端用户档案）；
   - 关闭弹窗，回到首页正常使用。
4. 用户在阶段 3 点击“开启我的微醺手记”后：
   - 设置 `onboardingCompleted = true`；
   - 设置 `onboardingFinishType = completed`；
   - 持久化 `isNewUser = false`（本地 + 服务端用户档案）；
   - 关闭弹窗，回到首页正常使用。
5. 若状态落库失败，需重试或回滚提示，避免重复弹窗与数据不一致。

## 5. 非功能与体验要求

### 5.1 性能要求
- 弹窗首屏出现时间不应显著拖慢首页可用性（建议异步加载视频资源）。
- 视频建议提供压缩版本与封面图，降低首播等待时间。

### 5.2 兼容与容错
- 适配主流 iOS/Android 微信小程序环境。
- 视频加载失败时显示兜底文案与“重试播放”入口，不阻断“下一步”操作。

### 5.3 文案与品牌一致性
- 文案语气保持“轻松、克制、有温度”，突出记录与分享美好时刻的品牌调性。

---

## 6. 验收标准（Acceptance Criteria）

1. 当账号被识别为新用户时，首次进入首页自动弹出三阶段演示。
2. 演示按 1 → 2 → 3 顺序进行，用户通过点击按钮进入下一阶段。
3. 用户在任意阶段可点击“跳过”，结束演示并回到首页。
4. 每个阶段均展示对应视频与说明文案，且界面中不包含阶段标题区。
5. 第三阶段点击“开启我的微醺手记”后，演示结束并正确落库“已完成”状态。
6. 用户点击“跳过”后，正确落库“已完成（跳过）”状态。
7. 已完成演示（观看完成或跳过）的用户再次进入首页，不再自动弹出该弹窗。
8. 弱网/视频失败场景下流程可继续，且不会造成页面卡死或功能阻断。

## 7. 技术实现方案（供研发评审）

### 7.1 配置化内容管理
- 三阶段文案与视频地址采用配置化（本地配置或远端下发），便于后续替换内容。
- 阶段配置不包含“阶段标题字段”，确保前端不渲染标题区。

### 7.2 新用户判定来源
- 优先以服务端用户档案字段为准（如 `onboardingCompleted`），本地缓存作加速与兜底。

### 7.3 视频资源与预缓存方案（腾讯云开发）
- 视频文件由你提供后，统一上传至腾讯云开发云存储（`cloud://<env-id>/onboarding/step1.mp4` 等路径）。
- 小程序端在首页初始化阶段执行预缓存：
  1. 调用云函数/接口获取 3 个视频的临时访问链接；
  2. 使用 `wx.downloadFile` 预下载到本地临时文件；
  3. 下载成功后将本地 `tempFilePath` 写入内存缓存（可选持久化到本地缓存，附带过期时间）。
- 弹窗播放时优先使用本地 `tempFilePath`，其次回退到临时链接，最后回退到默认兜底视频或静态引导图。

### 7.4 保证视频可播放的关键措施
1. **格式约束**：统一使用 H.264 编码的 MP4，控制分辨率与码率，避免机型兼容问题。
2. **可用性校验**：发布前对 3 个视频执行真机全链路验证（上传、下载、播放、切阶段）。
3. **播放前检查**：渲染前校验本地路径是否存在/可读，不可用时自动切换备用源。
4. **失败重试机制**：下载失败、播放失败分别至少重试 1 次，并给出明确的“重试播放”按钮。
5. **弱网降级策略**：若视频持续不可用，展示对应阶段文案与静态封面，允许继续“下一步/跳过”。

### 7.5 开发拆分建议
1. 首页新增新手弹窗组件与状态控制。
2. 新用户判定与状态持久化接口联调。
3. 腾讯云存储视频接入、预缓存与回退逻辑。
4. 播放失败重试、弱网降级与真机兼容性验证。

### 7.6 风险点
- 弱网导致视频下载慢或失败；
- 状态同步不一致可能导致重复弹窗；
- 云存储临时链接过期或权限配置错误导致无法播放。
